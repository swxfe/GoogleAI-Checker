# Bundled UI fonts

Regular, subsetted instances of Noto Sans SC and Noto Sans Arabic, from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/notosanssc
- https://github.com/google/fonts/tree/main/ofl/notosansarabic

CJK glyphs, punctuation and Arabic / Persian presentation forms are retained. The adjacent OFL files preserve the original copyright and license. FONT-LICENSES.txt accompanies packaged executables.
