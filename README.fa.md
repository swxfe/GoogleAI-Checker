# Google AI Checker

[English](README.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [فارسی](README.fa.md)

بررسی کنید کدام پروفایل‌های Throne شما به Google AI Studio دسترسی دارند.

تا ۱۰ بررسی هم‌زمان؛ در آزمایش محلی، **۵۲ پروفایل در حدود ۸ ثانیه** بررسی شد. زمان واقعی به پراکسی‌ها و شبکه بستگی دارد.

![نمای Google AI Checker با پروفایل‌های نمایشی](assets/demo.png)

*پروفایل‌های تصویر نمایشی هستند و نتیجهٔ بررسی واقعی نیستند.*

## استفاده

فایل ZIP را از [Releases](../../releases) بگیرید و کل پوشه را استخراج کنید. Throne در بسته موجود است.

1. برنامه را باز کنید و پایگاه دادهٔ Throne خود را انتخاب کنید.
2. مرورگر را انتخاب کنید و **ورود** را بزنید. پس از ورود به Google، روی **انجام شد** بزنید.
3. گروه را انتخاب کنید و **شروع** را بزنید. دکمهٔ **↻** یک پروفایل را دوباره بررسی می‌کند و **کپی**، پیکربندی JSON آن را کپی می‌کند.

برنامه با هستهٔ رسمی Throne، درخواست‌های هم‌زمان به AI Studio می‌فرستد. دریافت فهرست مدل‌ها دسترسی را تأیید می‌کند؛ زمان پاسخ شامل اتصال به پراکسی و درخواست HTTPS است. نتایج و اطلاعات ورود در پوشهٔ `sandbox_data/` کنار برنامه می‌مانند. پس از تغییر پروفایل‌ها در Throne، **تازه‌سازی** را بزنید.

## سیستم‌ها

| سیستم | وضعیت ساخت |
| --- | --- |
| Windows x64 ‏(DirectX 12) | ZIP ساخته و بررسی شده است |
| Linux x64 دسکتاپ | CI تنظیم شده؛ ساخت هنوز تأیید نشده است |
| macOS Intel / Apple Silicon | CI تنظیم شده؛ ساخت‌ها هنوز تأیید نشده‌اند |

تاکنون فقط ZIP ویندوز ساخته و بررسی شده است. Linux و macOS هنوز به اجرای موفق CI نیاز دارند.

## ساخت

به Rust 1.98+ با edition 2024، ابزارهای C/C++ ‏(MSVC در Windows)، Git، CMake، Perl، libclang و curl نیاز دارید.

```sh
cargo xtask dist
```

فایل ZIP و چک‌سام در `target/dist/` ساخته می‌شوند. برای تغییر نسخهٔ Throne، فقط شمارهٔ نسخه را در [`throne-version.txt`](throne-version.txt) تغییر دهید. `xtask` آرشیو مناسب و SHA-256 آن را از GitHub می‌گیرد و دانلود و بسته‌بندی را انجام می‌دهد.

GitHub Actions برای ساخت چهار بسته و بارگذاری آن‌ها در GitHub Releases هنگام ارسال تگ `v*` تنظیم شده است. ترجمه‌ها در `locales/` هستند؛ کلیدهای همهٔ زبان‌ها همان متن انگلیسی در `en.json` هستند.

## قدردانی

[Throne](https://github.com/throneproj/Throne) هستهٔ پراکسی و مدیریت پروفایل‌ها را فراهم می‌کند. این ابزار با استفاده از [API آن](https://github.com/throneproj/Throne-api) ساخته شده است. فونت‌ها از [Noto](https://fonts.google.com/noto) و پرچم‌ها از [Twemoji](https://github.com/jdecked/twemoji) هستند. مجوزهای شخص ثالث در `FONT-LICENSES.txt` آمده‌اند.
